# Phase 2: The Discipline of Verification & OSINT Fundamentals

## Overview

Phase 2 focuses on hands-on open-source intelligence (OSINT) and visual forensic methodologies. Grounded in the discipline of verification, students acquire tools to interrogate digital assets, uncover temporal and spatial manipulations, and establish an unbroken chain of custody for digital evidence.

---

## Core Focus Areas

- **Visual Provenance & Reverse Searching:** Utilizing tools such as RevEye, TinEye, Google Lens, and Yandex to locate the earliest indexed instance of an image across the global web.
- **EXIF & Forensic Metadata:** Extracting camera parameters, timestamps, device fingerprints, and GPS coordinates using FotoForensics, Jeffrey's Image Metadata Viewer, and command-line tools.
- **Audiovisual Fragmentation & InVID:** Deconstructing viral video clips into static keyframes, running forensic noise analysis, and detecting digital splicing or GAN artifacts.
- **Chronolocation & Geolocation:** Triangulating real-world geography by comparing shadows (SunCalc), topography, architectural landmarks, street signage, and satellite imagery (Google Earth, Wikimapia).
- **Entity & Business Verification:** Interrogating corporate registries, WHOIS records, Trustpilot reviews, and digital footprinting to detect fraudulent operations.

## How to Contribute

Document verified OSINT workflows, tool evaluation comparisons, or step-by-step geolocation breakdowns:

1. Create a new markdown file: `phase-2-verification/[technique-or-tool]-[your-name].md`
2. Follow the repository [Contribution Template](../README.md#contribution-template).
3. Ensure all evidence includes permanent archive links (Wayback Machine / Archive.today).
4. Submit a Pull Request targeting `main`.
