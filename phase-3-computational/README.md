## Overview

Phase 3 scales journalistic inquiry through programmatic automation. Moving beyond manual search limitations, students write structured Python code to extract data from public records, parse chaotic HTML structures, clean messy datasets, and manage secure virtual environments.

---

## Core Focus Areas

- **Automated Web Scraping:** Writing resilient scrapers using Python, `BeautifulSoup`, `requests`, and `Selenium`/`Playwright` for dynamic JavaScript-rendered registries.
- **Data Wrangling & Analysis:** Utilizing `pandas` to clean, restructure, filter, and analyze structured and semi-structured datasets.
- **Scraping Ethics & Lawful Ingestion:** Adhering to `robots.txt`, applying request throttling (`time.sleep`), handling public vs. private endpoints, and preventing denial-of-service pressure on public servers.
- **Reproducible Research Environments:** Managing dependencies via `requirements.txt`, virtual environments (`venv` / `conda`), and browser-based computational workbenches (GitHub Codespaces / Google Colab).
- **Digital Chain of Custody:** Cryptographic hashing (SHA-256) of raw extracted datasets before transformation to guarantee evidentiary integrity.

4. **Follow the Template:** Fill out the [Contribution Template](https://github.com/cyowell/jour3318-knowledge-base#contribution-template). Ensure scripts are commented and contain no private API keys.
